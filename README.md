# Exercício 02 - Comparação de Números em Java

## Sobre o projeto
Programa desenvolvido em Java para comparar dois números inteiros informados pelo usuário.

## Funcionalidades
- Solicita dois números inteiros.
- Verifica se os números são iguais.
- Identifica se o primeiro número é maior.
- Identifica se o segundo número é maior.

## Conceitos praticados
- Scanner
- Variáveis do tipo int
- Estruturas condicionais (if, else if e else)
- Operadores relacionais
- Lógica de programação

## Tecnologias utilizadas
- Java
- IntelliJ IDEA

## Objetivo
Praticar os fundamentos da linguagem Java e desenvolver
o raciocínio lógico por meio de estruturas condicionais.
